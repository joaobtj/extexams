# extexams

<!-- badges: start -->

<!-- badges: end -->

**Extended Tools for Dynamic Academic Exams Generation**

`extexams` provides an extended framework and custom LaTeX templates
built on top of the R `exams` package. Originally developed for personal
teaching purposes, it automates the generation of randomized batch
exercises and personalized, roster-based academic exams.

## Installation

You can install the development version of `extexams` from
[GitHub](https://github.com/joaobtj/extexams) with:

``` r
# install.packages("devtools")
devtools::install_github("joaobtj/extexams")
```
